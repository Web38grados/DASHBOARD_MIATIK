# Dashboard Miatik

Proyecto base construido con React, TypeScript y Vite.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

## Estructura de `src`

- `application/adapters`: adaptadores de servicios e infraestructura.
- `application/components`: componentes reutilizables de aplicación.
- `application/services`: casos de uso y servicios.
- `assets`: recursos importados por módulos.
- `domain`: modelos y reglas del dominio.
- `presentation/views`: vistas de la interfaz.
- `static`: recursos estáticos propios de la aplicación.
- `styles`: estilos compartidos.
- `App.tsx`, `webRoutes.tsx` y `main.tsx`: composición, rutas y punto de entrada.
